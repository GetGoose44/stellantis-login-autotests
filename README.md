# Тестовое задание AQ — stellantis.autocrm.ru

Автотесты на Playwright + TypeScript для формы авторизации.

## Структура
- `tests/login.spec.ts` — функциональные автотесты (п.1 задания): невалидные логин/пароль,
  пустые поля, маскировка пароля, переход по "Забыли пароль".
- `src/pages/LoginPage.ts` — Page Object формы логина.
- `src/helpers/seedTestUser.ts` — пример хелпера, вставляющего тестового пользователя
  перед тестом авторизации без реального подключения к БД (п.2).
- `src/api/createUser.example.ts` — пример API-запроса на создание пользователя (п.3).
- `ADDITIONAL_SCENARIOS.md` — какие ещё сценарии стоит проверить для формы авторизации (п.4).

## Запуск
```bash
npm install
npx playwright install chromium
npm test
```

Тесты проверены и проходят против реального `https://stellantis.autocrm.ru/login`
(4/4 passed на момент подготовки задания).

### Важный нюанс
Сайт отдаёт интерфейс на английском языке, если у браузера/окружения локаль по умолчанию
не `ru-RU` (проверяется по `Accept-Language`). Поэтому `LoginPage.goto()` явно открывает
`/login?language=ru_RU`, чтобы тесты не были "плавающими" в зависимости от окружения CI.
